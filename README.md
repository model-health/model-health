# Model Health SDK

SDK for biomechanical analysis from smartphone videos.

## Installation

### Swift Package Manager

```swift
dependencies: [
    .package(url: "https://github.com/model-health/model-health-swift.git", from: "0.1.27")
]
```

### npm

```bash
npm install @modelhealth/modelhealth@0.1.27
```
