# 0.1.0 (14)
### 10-Dec-2025

## Deprecated APIs
```
public func trialList() async throws -> [Trial]
```
```
public func videoList() async throws -> [Video]
```

## Updated APIs

`sessionList()` no longer returns the trials associated with a session. You should use the new `trialList(for:)` to retrive the trials per session.

# What's new

- Added support for accessing trials per session
- Video and analysis data downloads.

## Accessing trials
Trials are now retreived per session, rather than as part of the `Session`.

### API
```
public func trialList(for session: Session) async throws -> [Trial] 
```
Retrieves all movement trials associated with the authenticated account.

Trials represent individual recording sessions and contain references to captured videos and analysis results. Use this to review past data or fetch analysis for completed trials.

```swift
let trials = try await sdk.trialList(for: session)

// Find completed trials ready for analysis
let completed = trials.filter { $0.status == "completed" }

// Access videos and results
for trial in completed {
    print("Trial: \(trial.name ?? trial.id)")
    print("Videos: \(trial.videos.count)")
    print("Results: \(trial.results.count)")
}
```

- Parameters: `session` The session to retrieve trials for
- Returns: An array of ``Trial`` objects
- Throws: An error if the request fails or authentication has expired

## Video downloads
Users can now download video files associated with trials.

### API

```swift
public func videos(for trial: Trial, version: VideoVersion) async -> [Data]
```

#### Types
```
enum VideoVersion {
    // The original, unprocessed video as captured or uploaded.
    case raw

    // Videos that have been synchronized.
    case synced
}
```

#### Discussion

Asynchronously fetches all videos associated with a given trial that match the specified type. Videos with invalid URLs or failed downloads are silently excluded from the result.

- Parameters:
  - trial: The trial whose videos should be downloaded.
  - version: The version type of videos to download (e.g., raw, processed).
 
- Returns: An array of `Data` objects containing the video data. The array may be empty if no valid videos are available or all downloads fail.

- Note: This method performs concurrent downloads for optimal performance. Individual download
        failures do not affect other requests.

#### Example
```swift
let trial = // ... obtained trial
let videoData = await sdk.videos(for: trial, version: .raw)

for data in videoData {
    // Process video data
}
```

## Analysis data downloads
Users can now download data files for certain types of data.

### API

```swift
public func data(ofType types: Set<ResultDataType>, for trial: Trial) async -> [ResultData]
```

#### Types
**ResultDataType**

```swift
enum ResultDataType {
    // Visualization data for interpreting movement analysis results.
    case visualization

    // Raw kinematic data including joint positions, angles, and velocities.
    case kinematic
}
```

Use this to specify what type of result data you want to retrieve.

**ResultData**

```swift
struct ResultData {
    // The format of the result data file.
    public enum FileType: Sendable {
        // JSON-formatted data, suitable for structured parsing
        case json
        // CSV-formatted data, suitable for spreadsheet import or manual inspection
        case csv
    }

    // The format of this result file
    let fileType: FileType

    // The raw file data
    let data: Data
}
```

This is returned by `data(ofType:for:)` and combines the resulting data with it's file type for easy identification when parsing the contents.

#### Discussion

Downloads result data files from a processed trial.

After a trial completes processing, various result files become available for download.
Use this method to retrieve specific types of data (kinematic measurements, visualizations)
in their native file formats (JSON, CSV).

This method is useful when you need access to raw analysis data rather than the
structured metrics provided by ``downloadAnalysisResult(forTrial:resultTag:)``.

- Parameters:
  - types: The types of result data to download (kinematic, visualization, or both)
  - trial: The completed trial to download data from
- Returns: An array of result files with their formats. Returns an empty array if no
  results are available or all downloads fail.
  

**Note:** This method performs concurrent downloads for optimal performance. Individual download failures do not affect other requests and failed downloads are silently excluded from results.


#### Example
```swift
// Download kinematic data only
let kinematicData = await service.data(ofType: [.kinematic], for: trial)

for result in kinematicData {
    switch result.fileType {
    case .json:
        let decoder = JSONDecoder()
        if let jsonData = try? decoder.decode([String: Any].self, from: result.data) {
            print("Parsed kinematic JSON")
        }

    case .csv:
        if let csvString = String(data: result.data, encoding: .utf8) {
            print("CSV data:\n\(csvString)")
        }
    }
}

// Download all available data types
let allData = await service.data(
    ofType: [.kinematic, .visualization],
    for: trial
)
print("Downloaded \(allData.count) result files")
```
